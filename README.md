# Development Environment Setup Guide

This is a guide to set up your local development environment

## Prerequisites

Make sure you have the following setup on your system:

- [oh-my-zsh](/docs/tools/oh-my-zsh.md)
- [Homebrew](/docs/tools/homebrew.md)
- [Git](/docs/tools/git.md)

## Applications

Here are some applications highly recommended for development:

- [iTerm2](/docs/applications/iterm2.md)
- [Visual Studio Code](/docs/applications/visual-studio-code.md)
- [Google Antigravity](/docs/applications/antigravity.md)
