# Google Antigravity

Check out [Google Antigravity](https://antigravity.app/) official website

## installation

To install Google Antigravity by homebrew, run the following command in your terminal:

```sh
brew install --cask antigravity
```

## configuration

### Browser

Antigravity may complain about Chrome not being installed
Set Browser to Chrome with the following path:
```
~/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome
```
