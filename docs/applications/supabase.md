# Supabase

[Supabase](https://supabase.com/) is an open source Firebase alternative.

## Installation

To install the Supabase CLI via Homebrew, run the following command in your terminal:

```sh
brew install supabase/tap/supabase
```

## Usage

Here are some common commands for using the Supabase CLI:

### Login

To login to the Supabase CLI:

```sh
supabase login
```

### Initialize

To initialize a new Supabase project:

```sh
supabase init
```

### Start

To start the local Supabase stack:

```sh
supabase start
```

### Stop

To stop the local Supabase stack:

```sh
supabase stop
```

For more details, refer to the [official Supabase CLI documentation](https://supabase.com/docs/guides/cli).
